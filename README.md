# CCNA Network Labs
Hands-on networking labs and projects completed while studying Cisco CCNA 200-301 concepts, with a focus on practical networking and cybersecurity fundamentals.
## About This Repository
This repository documents my practical learning journey through Cisco CCNA networking concepts.
The labs are created using Cisco Packet Tracer and, where appropriate, EVE-NG.
## Topics Covered
Network Fundamentals
OSI and TCP/IP Models
IPv4 and IPv6
Subnetting
Ethernet and MAC Addresses
Switching
VLANs
Routing
DHCP
DNS
NAT
Access Control Lists (ACLs)
Network Security Fundamentals
Network Troubleshooting
## Lab Structure
Each lab will contain:
Objective
Network topology
Configuration
Testing
Screenshots
Results
Lessons Learned
## Tools
Cisco Packet Tracer

Ubuntu Linux
## Goal
Build a strong practical networking foundation for a career in cybersecurity.
