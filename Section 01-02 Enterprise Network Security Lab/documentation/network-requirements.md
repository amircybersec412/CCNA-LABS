# Network Requirements

## Business Requirements

SecureTech Corporation requires a segmented enterprise network supporting multiple departments and security zones.

The network must provide:

- Separate network segments for departments.
- Reliable communication between authorized networks.
- Isolation of Guest users from sensitive internal resources.
- Dedicated server network.
- Dedicated Security Operations network.
- Dedicated network administration segment.
- Centralized routing between VLANs.
- Automatic IP address assignment using DHCP.
- Basic infrastructure security controls.
- Ability to test and verify security policies.

## Security Requirements

1. Guest users should not have unrestricted access to internal networks.
2. Sensitive departments should be logically separated.
3. Servers should be placed in a dedicated network segment.
4. Network administration should use a dedicated management segment.
5. Security monitoring infrastructure should be separated from normal users.
6. Access-control policies should follow least-privilege principles.
7. Network configurations should be verified and documented.
