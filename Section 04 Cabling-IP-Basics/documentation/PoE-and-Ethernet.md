# PoE and Ethernet

## Power over Ethernet
PoE stands for **Power over Ethernet**. It allows compatible network equipment to receive electrical power and network data through Ethernet cabling.

Examples:
- IP phones
- Wireless access points
- Some security cameras

The IP phone in this lab demonstrates the PoE concept.

**Note:** PoE is primarily a hardware/switch capability, and exact behavior depends on the Packet Tracer switch and endpoint model.

## Shared Media
Shared-media Ethernet means multiple devices use a common communication medium. A traditional Ethernet hub is a classic example.

## Point-to-Point Ethernet
A point-to-point link directly connects two network devices:

R1 -------- SW1


Modern switched Ethernet commonly uses dedicated point-to-point links.

## Fiber
**Single-mode:** generally longer-distance links.
**Multimode:** generally shorter-distance building/data-center links.
