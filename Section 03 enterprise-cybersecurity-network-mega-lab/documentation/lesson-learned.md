# Lessons Learned

- I learned how to design a complete enterprise network architecture.
- I learned how 3-tier campus architecture separates core, distribution, and access functions.
- I learned how VLANs provide network segmentation.
- I learned how trunk links carry multiple VLANs.
- I learned how Layer 3 switching provides inter-VLAN routing.
- I learned how enterprise servers can be separated into dedicated networks.
- I learned how WAN routers connect different network locations.
- I learned how cloud networking can be integrated with an enterprise network.
- I learned how a SOHO branch connects to an enterprise environment.
- I learned how spine-leaf architecture is used in data-center networks.
- I learned how OSPF provides dynamic routing.
- I learned how SSH secures remote device management.
- I learned how port security protects access ports.
- I learned how PortFast and BPDU Guard protect endpoint interfaces.
- I learned how disabling unused ports reduces the attack surface.
- I learned how to troubleshoot VLAN and connectivity problems.
- I learned how to verify a network using Cisco IOS show commands.
- I learned how to document a complete networking and cybersecurity project.
